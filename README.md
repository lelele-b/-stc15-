# 基于 STC15 的多模态环境监测装置

基于 **STC15F2K60S2** 的多模态环境监测装置。8 位数码管分页轮显时间、温度、实时光照与历史最大光照，数据掉同时通过串口每秒向上位机上报一行当前时间实时温度实时光照。

## 功能

| 页面 | 显示内容 | 示例 |
|---|---|---|
| 时间 | `HH-MM-SS` | `12-30-45` |
| 温度 | `t` + 一位小数 | `t25.6` |
| 实时光照 | `L` + 0~255 | `L 128` |
| 历史最大光照 | `H` + 0~255 | `H 200` |

- 4 个按键翻页（`S13`/`S12` 下一屏，`S17`/`S16` 上一屏），带 30ms 消抖与 120ms 连跳抑制
- 最大光照 / 最高温度写入 AT24C02，重新上电后仍在（带校验，校验失败自动从零开始记）
- 串口 9600 8N1 每秒上报：
  ```
  26-01-01 12:00:00 T=25.5 L=94 H=176
  ```
  其中 `RTC=ERR` 表示 DS1302 没读到合法时间，此时数码管改显诊断码 `E<path> <秒寄存器原值>`

## 硬件与引脚

| 外设 | 接口 | 引脚 |
|---|---|---|
| 数码管段码 | P0 → 74HC573(位选 Y7) | `P0` |
| 数码管位选 | P0 → 74HC573(Y6) | `P0` |
| 574/573 通道选择 | 74HC138 | `P2.5` / `P2.6` / `P2.7` |
| 锁存器写使能 | — | `P4.2` |
| DS1302 时钟 | 三线 | `CE=P1.3`、`SCK=P1.7`、`IO=P2.3` |
| DS18B20 温度 | 单总线 | `P1.4`（板上 10k 上拉） |
| PCF8591（光敏 AIN1 / 电位器 AIN3） | I2C | `SCL=P2.0`、`SDA=P2.1` |
| AT24C02 | I2C（与 PCF8591 同一总线） | `SCL=P2.0`、`SDA=P2.1` |
| 矩阵键盘 | — | 行 `P3.2`/`P3.3`，列 `P3.5`/`P3.4` |
| 串口 | UART1 | `P3.0` / `P3.1`，9600 8N1 |

主频 **11.0592MHz**。定时器 0 提供 1ms 时基与数码管扫描，定时器 2（1T，不分频）作为微秒计数器供 `Delay_Us` 使用。

## 编译

**Keil µVision**：打开 `project.uvproj`，`F7` 编译，产物 `Objects/project.hex`。

**命令行**（Keil C51 V9.54）：

```bat
C51.EXE System\RTC.c INCDIR(.\User;.\System;.\Hardware;%KEIL%\C51\INC;%KEIL%\C51\INC\STC) OBJECT(.\Objects\RTC.obj)
BL51.EXE @.\Objects\project.lnp
OH51.EXE project
```

下载用 STC-ISP，注意选择 **STC15F2K60S2**、**11.0592MHz**。

## 编码说明

`User/`、`System/`、`Hardware/` 下的 `.c/.h` 在工作区里是 **GBK** 编码（中文注释），仓库里通过 [`.gitattributes`](.gitattributes) 的 `working-tree-encoding=GBK` 统一以 UTF-8 存储。

- GitHub 网页上中文注释能正常显示
- `git clone` 下来的文件仍是 GBK，µVision / C51 可以直接编译

**如果你用编辑器打开看到乱码，把文件编码切到 GBK 即可；不要用 UTF-8 重新保存**，否则 µVision 里注释会变成乱码（虽然不影响编译）。

## 调试状态

DS1302 目前读不到时间，串口上报 `RTC=ERR`。已在开机时输出诊断行辅助定位：

```
RTCRAW 255 255 255 255 255 255 path=3 ram=255 probe=63
```

| 字段 | 含义 |
|---|---|
| `RTCRAW` 六个值 | 秒/分/时/日/月/年寄存器原值。`255`=芯片没应答，`0`=数据线被拉低 |
| `path` | 0=正常，1=CH 停振写了默认时间，2=数据非法写了默认时间，3=秒寄存器读不合法 |
| `ram` | 往 DS1302 RAM 写 `0x5A` 再读回，`90` 说明三线通、芯片正常 |
| `probe` | `P1.3`/`P1.7`/`P2.3` 六向电平自检，`63` 表示三根线都能正常拉高拉低 |
